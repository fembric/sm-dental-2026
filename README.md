# СМ-Стоматология — новая версия сайта

Многостраничный адаптивный сайт, подготовленный 2 октября 2026 года на основе папки «сайт образец». Оригинальный бэкап не изменён.

## Что готово

20 содержательных страниц и отдельная страница ошибки 404: главная; каталог услуг; 6 отдельных услуг; врачи; клиника; пациентам; стоимость; журнал; 3 памятки; контакты; документы; конфиденциальность; структура зуба.

Поиск и фильтры услуг, диалог записи с телефонными ссылками, интерактивный список подготовки с печатью и сбросом, раскрывающиеся ответы, мобильное меню, увеличение текста, плавное появление секций. Учтена системная настройка уменьшения анимаций. Все изображения и стили локальные; внешних шрифтов и аналитических счётчиков нет.

## Запуск и редактирование

Нужен Node.js 22 LTS с npm. Установка дополнительных пакетов не требуется. Исходные файлы находятся в public/, результат сборки — в dist/. Не редактируйте dist вручную.

```sh
npm run build
npm run check
npm start
```

Адрес локального просмотра: http://127.0.0.1:4286

Содержимое и шаблоны страниц — `build.mjs`. Стили — `dist/assets/style.css` и `dist/assets/update.css`; интерактивность — `dist/assets/app.js` и `dist/assets/update.js`. Цены — `price-data.mjs`, схема зуба — `tooth-page.mjs`. После изменения текстов запустите `node build.mjs` и обновите страницу. Готовые HTML-страницы находятся в `dist`; их можно разместить на статическом хостинге. Открывать `index.html` двойным щелчком не следует: адреса ресурсов рассчитаны на HTTP-сервер.

## Что нужно подтвердить перед запуском для пациентов

Текущие телефоны, адрес, email и расписание; состав команды, специальности, образование и аккредитации; дату вступления прайсов в силу; реквизиты юридического лица, сведения о лицензии и реальные документы клиники. В макете нет вымышленных дипломов, стажа, отзывов, рейтингов, цен и обещаний результата. Старые акции 390 ₽ и 25 000 ₽ не перенесены как действующие.

Страница документов позволяет связаться с клиникой; она не заменяет размещение действующих документов. Тексты об услугах и памятки необходимо согласовать с медицинским руководителем перед публичным запуском. Три дополнительно предоставленные фотографии сопоставлены с врачами по фамилиям файлов. Сведения о специальностях и квалификации не выдумывались.

Предварительные заявки сохраняются локально в браузере с явным согласием пользователя. Форма содержит имя, телефон, дату и время (Москва), календарь на 90 дней, просмотр, удаление и скачивание JSON. Отправки в клинику, общей базы, авторизации администратора и блокировки времени пока нет. Подтверждение приёма — по телефону.

Тестовая версия подготовлена для GitHub Pages. Домен и DNS не меняются. Инструкция — GITHUB-PAGES.md. robots.txt запрещает индексацию, но не ограничивает публичный доступ.

Два значения герметизации фиссур 390 и 450 рублей в исходном документе расходятся, поэтому в подборку они не включены; полный документ сохранён.

Страница /tooth/ содержит интерактивную SVG-схему с четырьмя расходящимися слоями. Обычная прокрутка колёсиком или свайпом управляет схемой, без перехвата прокрутки. Есть выбор этапа кнопками, статический режим и поддержка prefers-reduced-motion. Текстовые описания доступны ниже схемы независимо от анимации. Источник: https://www.mouthhealthy.org/all-topics-a-z/tooth .



## Логотип и предварительная запись

Выбранная монограмма СМ адаптирована в SVG: public/assets/logo-mark.svg. Используется в шапке, подвале и значке вкладки. booking-dialog.mjs задаёт форму, public/assets/booking.js отвечает за локальные черновики. При подключении базы потребуется серверная проверка времени и защищённый просмотр администратором.
